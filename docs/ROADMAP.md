# Roadmap

Implemented foundation: private owner workspace, bounded synthetic training, NIfTI inspection, affine voxel/slice display, persisted experiments, reports, checksums, native client source and build workflows.

Next engineering gates: isolated parsing workers with hard timeouts, transactionally durable job dispatch, backup/restore drills, broader accessibility and platform testing, signed native distribution and institutional deployment hardening. PostgreSQL/object storage/distributed queue only when tested deployment needs them.

Next science gates: approved dataset and endpoint, frozen inclusion/label rules, validated preprocessing/derived features, participant/site duplicate audit, simple baseline, independent external evaluation, calibration and clinically meaningful subgroup assessment. Add segmentation, connectivity, longitudinal, multimodal or foundation-model methods only with data, licensing, hardware and validation appropriate to each endpoint. No timeline or clinical performance is promised.
