NeuroMap AI 0.1.0 is a research foundation prerelease: image inspection, a synthetic classification workflow, computed reports and a private dashboard. It does not diagnose disease or provide clinical risk predictions.

Web bundle requires the Python API and configured proxy. Windows client requires an available frontend/API server; it has no offline ML runtime. Native code signing is not asserted. Android APK and iOS IPA are unavailable unless separately built, signed and verified; source projects are provided.

Read docs/VERIFICATION.md, docs/RELEASE_AND_SIGNING.md and SHA256SUMS.txt. Reported metrics are synthetic engineering outputs only. No real patient data, pretrained weights or restricted datasets are distributed.
