# Security policy

Do not publish sensitive uploads, credentials or exploit details in a public issue. Use the repository's private GitHub vulnerability reporting feature if enabled; otherwise open a minimal non-sensitive issue requesting a private reporting channel. No response SLA or clinical support is promised. Release 0.1.0 is the only maintained foundation line. See [security/threat model](docs/SECURITY_AND_PRIVACY.md) and [limitations](docs/SAFETY_AND_LIMITATIONS.md). Do not deploy as a public clinical-upload service.
