## Onboarding gate

Record dataset version/DOI, checksum manifest, license/DUA, authorized users, consent/ethics constraints, retention deadline, inclusion/exclusion rules, participant/visit/site identifiers, label timing, acquisition protocol and preprocessing versions. Deduplicate before splitting. Independently review faces and metadata. Verify scanner- and site-level generalization before model claims. See [dataset card](research/DATASET_CARD.md).
